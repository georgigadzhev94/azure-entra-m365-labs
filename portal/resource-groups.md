# Azure Resource Groups — Portal Lab

## Objective

Practice creating and organizing Azure Resource Groups using the Azure Portal.

## Resource Created

| Property | Value |
|---|---|
| Resource Group | `rg-m1-portal-weu` |
| Region | West Europe |
| Environment | Lab |
| Purpose | Training |
| Owner | Student |

## Resource Lock

A resource lock named `M1-Prevent-Deletion` was configured with the `CanNotDelete` level.

This lock helps prevent accidental deletion of the Resource Group and resources within its scope. The lock must be removed before the protected Resource Group can be deleted.

## What I Learned

- How to create a Resource Group in the Azure Portal.
- How to select a region.
- How to organize resources using tags.
- How to protect resources from accidental deletion using resource locks.

## Verification

The Resource Group, its tags, and the resource lock were checked in the Azure Portal.
